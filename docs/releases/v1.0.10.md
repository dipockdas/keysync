## keysync v1.0.10

Feature release: secure team secret sharing without accounts or a keysync-hosted service.

### Highlights

**`keysync share` / `keysync accept`** — Share selected project keys (or one key with `-k`) as an encrypted `.ksx` bundle. Two transports:

- **File mode** (default): write `my-app.keysync.ksx`; bundles expire after **10 minutes**
- **Magic Wormhole**: transfer the same encrypted payload via a pairing code; sessions time out after **5 minutes**

Security model: Argon2id + XChaCha20-Poly1305 payload encryption with an interactive passphrase (independent of the Wormhole pairing code). Type **`SHARE`** to create/send and **`ACCEPT`** to import. Existing destination keys are skipped in v1.

### Examples

```bash
keysync share -p my-app --file
keysync accept ./my-app.keysync.ksx

keysync share -p my-app --wormhole
keysync accept 7-purple-dolphin

keysync share -p my-app -k DATABASE_URL --file
```

Send the file/code and passphrase through different channels. See [SECURITY.md](https://github.com/dipockdas/keysync/blob/main/SECURITY.md#sharing-secrets-with-teammates) and [architecture](https://github.com/dipockdas/keysync/blob/main/docs/architecture.md#sharing-secrets).

### Upgrade

```bash
brew update && brew upgrade keysync
```

On macOS after replacing the binary: `keysync trust` once if you use a new install path or unsigned local build.

Manual install: download from this release, replace `keysync`, then `keysync trust` on macOS.
