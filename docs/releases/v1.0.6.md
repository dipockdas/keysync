## keysync v1.0.6

Minor update: improved `keysync list` / `keysync ls` output and scope filtering.

### What's new

**Grouped output** — Secrets are organized by scope instead of a flat table:

- **Global** section first (with key count)
- **Project** sections in alphabetical order
- **Environment** subgroups (`project-wide`, `production`, etc.)
- Blank lines between projects for easier scanning
- Keys sorted alphabetically within each group

**New `-g` / `--global` flag** — Explicit control over which scopes are listed:

| Command | Shows |
|---------|--------|
| `keysync ls` | All secrets, grouped |
| `keysync ls -g` | Global keys only |
| `keysync ls -p my-app` | Project keys only |
| `keysync ls -g -p my-app` | Global + project |

**Terminal color (macOS / Linux)** — Section headers and key names use color when stdout is a TTY. Windows stays plain text unless running in Windows Terminal.

### Breaking change (small)

`keysync ls -p PROJECT` **no longer includes global keys** by default. If you relied on the old behavior, add `-g`:

```bash
# Before (v1.0.5 and earlier): project + globals
keysync ls -p my-app

# Now: project only
keysync ls -p my-app

# To match old behavior:
keysync ls -g -p my-app
```

No changes to `get`, `set`, `export`, or `push` — only list display and filtering.

### Upgrade

**Homebrew:**

```bash
brew update && brew upgrade keysync
```

**Manual install:** Download the binary for your platform below, replace your existing `keysync`, then on macOS run `keysync trust` once.

See [Getting started](https://github.com/dipockdas/keysync/blob/main/docs/getting-started.md) for full usage.
