## keysync v1.0.8

Patch release: fixes `keysync ls -p NAME` and `keysync ls --project NAME` after the v1.0.7 project-names feature.

### Fixes

**`keysync ls --project hyperdx` showed all projects** — Bare `-p` / `--project` (no name) correctly lists project names, but a separate-arg project name (`keysync ls -p my-app` or `keysync ls --project my-app`) was misread as bare `-p`. Named projects now list that project's keys again.

### Upgrade

```bash
brew update && brew upgrade keysync
```

On macOS after replacing the binary: `keysync trust` once if you use a new install path or unsigned local build.

Manual install: download from this release, replace `keysync`, then `keysync trust` on macOS.
