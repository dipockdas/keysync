## keysync v1.0.9

Patch release: fixes `-p NAME` / `--project NAME` on `set`, `get`, `export`, `rm`, `mv`, and `rotate` (same Cobra parsing bug fixed for `list` in v1.0.8).

### Fixes

**`keysync set KEY=val -p geo` failed with "too many arguments"** — Bare `-p` uses a sentinel value so `keysync ls -p` can list project names; a separate-arg project name (`keysync set API_KEY=xxx -p geo`) was treated as an extra positional. All affected commands now resolve the trailing project name correctly.

### Tests

- User-path CLI tests run through `newRootCmd()` on every `make test`
- Binary subprocess tests: `make test-userpath`
- Manual smoke: `./scripts/test-userpath.sh`

### Upgrade

```bash
brew update && brew upgrade keysync
```

On macOS after replacing the binary: `keysync trust` once if you use a new install path or unsigned local build.

Manual install: download from this release, replace `keysync`, then `keysync trust` on macOS.
