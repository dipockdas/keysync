## keysync v1.0.11

Patch release: fixes `-p NAME` / `--project NAME` on `keysync share` (same Cobra parsing bug fixed for `set`, `get`, `export`, and others in v1.0.9).

### Fixes

**`keysync share -p geo` failed with "unknown command geo"** — Bare `-p` uses a sentinel value so `keysync list -p` can list project names; a separate-arg project name was treated as a subcommand. `share` now resolves the trailing project name the same way as other commands.

### Upgrade

```bash
brew update && brew upgrade keysync
```

On macOS after replacing the binary: `keysync trust` once if you use a new install path or unsigned local build.
