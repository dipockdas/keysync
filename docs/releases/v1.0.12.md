## keysync v1.0.12

Feature release: project shares now include environment-scoped secrets.

### Highlights

**`keysync share -p PROJECT`** now includes all keys stored under that project:

- Project-wide secrets (`keysync set -p PROJECT KEY=…` with no `--env`)
- Environment-scoped secrets (`keysync set -p PROJECT KEY=… --env production`, `--env dev`, etc.)

The manifest preview labels env keys (e.g. `DATABASE_URL (env: production)`). On accept, keys are imported into the same environment bucket on the recipient's machine. No separate `-e` flag is required.

Global secrets are still excluded from a full project share unless you use `-k KEY` and the key resolves from global fallback.

### Upgrade

```bash
brew update && brew upgrade keysync
```

On macOS after replacing the binary: `keysync trust` once if you use a new install path or unsigned local build.
