## keysync v1.0.7

Patch release: fixes macOS `keysync trust` on current macOS, improves trust UX, and adds `keysync ls -p` for project names.

### Fixes

**macOS keychain trust regression (v1.0.5–v1.0.6)** — `keysync trust` again grants this binary access without per-key login prompts:

- **Signed builds** (GitHub Releases, `make build-signed`): one login password, then silent partition-list updates via team ID.
- **Unsigned `make build`**: one login password, then application ACL updates (re-trust after each rebuild).
- Unlocks the login keychain once; finds items without reading secret values.
- Inline progress bar on stderr: `████████░░░░  32/59 trusted` (updates in place).

After upgrading, run `keysync trust` once per binary path. Use `make build-signed` for day-to-day macOS dev.

### What's new

**`keysync ls -p`** — List project names and key counts (no secret names):

```bash
keysync ls -p          # project names only
keysync ls -g -p       # globals + project summary
```

### Upgrade

**Homebrew** (after formula bump):

```bash
brew update && brew upgrade keysync
```

**Manual install:** Download the binary for your platform below, replace your existing `keysync`, then on macOS:

```bash
keysync trust
```

See [Troubleshooting — macOS keychain prompts](https://github.com/dipockdas/keysync/blob/main/docs/troubleshooting.md#macos-repeated-keychain-prompts).
